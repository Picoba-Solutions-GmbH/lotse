Execution

Every run starts a task pod in namespace {{ ov.location.execution_namespace }} and copies the package files to {{ ov.location.execution_workdir }}. Task pods are temporary. The package store is the only persistent copy.

Python environments are built once per version and cached. They can be rebuilt from requirements.txt, so backups leave them out.
